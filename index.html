Project Settings, two ways

Both pages do the same task: rename Apollo to Atlas, switch Europe to North America, and save. The UI SDK page lets an agent call snapshot() and act() on the components. The other page is a plain HTML form, so the same steps go through querySelector, input events, and a click.

With UI SDK Agent bridge: snapshot, then act by label. Without UI SDK Plain DOM: querySelector, set values, dispatch events, click Save.
